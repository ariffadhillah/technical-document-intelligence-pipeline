# Vehicle and Component Intelligence

Extract explicitly supported information about:

- vehicles
- vehicle variants
- manufacturers
- chassis
- engines
- transmissions
- axles
- driveline systems
- wheels
- tires
- hydraulic systems
- pneumatic systems
- electrical systems
- cabins
- bodies
- frames
- subframes
- fuel systems
- auxiliary equipment
- tools
- replacement parts
- product identifiers

For vehicles, capture when available:

- manufacturer
- model
- variant
- production year
- vehicle type
- drive configuration
- gross weight
- empty weight
- payload
- associated engine
- associated transmission

For engines, capture when available:

- manufacturer
- model
- engine type
- cylinder count
- displacement
- power
- torque
- fuel type
- cooling type

For transmissions, capture when available:

- manufacturer
- model
- transmission type
- gear count
- special operating characteristics

For parts and components, preserve:

- displayed name
- manufacturer
- manufacturer part number
- alternative part numbers
- model or product code
- compatibility
- material
- dimensions
- associated organization

Do not create a part number from descriptive prose.
